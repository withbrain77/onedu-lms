# Django 5.2 LTS 전환 검증

## 범위와 환경

- 기존 운영 기준 커밋: `d1c9e28`, Django 4.2.30.
- 전환 대상: `Django==5.2.17`. 배포할 패치 버전을 고정한다.
- Python 3.12를 별도 가상 환경에 설치해 기존 PC의 Python 3.8과 분리했다.
- 로컬 테스트는 별도 SQLite DB, CI는 운영과 같은 PostgreSQL 16을 사용한다.
- 가상 회원·강의·수강 기간·재수강 요청·시청 진도·수료증·파일을 사용한다. 운영 DB를 테스트 환경에 연결하지 않는다.
- 외부 메일, 자동 백업, 운영 영상 변환 작업을 테스트에서 실행하지 않는다.

## 검증 방법

1. 4.2.30으로 테스트 데이터를 생성하고 모든 모델 레코드와 업로드 파일 해시를 기록한다.
2. 같은 DB를 5.0 → 5.1 → 5.2에서 열어 기록·파일·기존 비밀번호·세션을 검증한다.
3. 각 버전에서 추가 마이그레이션이 없는지 확인한다. 새 마이그레이션이 발견되면 검증은 실패한다.
4. 5.2에서 서버 기능 테스트 231개와 모바일 브라우저 검사를 실행한다.
5. 같은 DB를 다시 4.2로 열어 복귀 가능 여부를 확인하고 5.2로 재전환한다.

재현 코드는 `tests/upgrade/rehearse.py`, 격리 설정은 `config/upgrade_test_settings.py`에 있다.
PostgreSQL은 `UPGRADE_TEST_DATABASE_URL`로 지정하며 루프백 주소의 `onedu_upgrade` DB만 허용한다.
CI의 `upgrade-rehearsal` 작업은 독립 PostgreSQL 컨테이너에서 이 과정을 반복한다.
비밀번호 재해시·로그인 시각·교실 접근 시 갱신되는 수강 레코드의 `updated_at`은 정상적인 변경으로 구분한다.
수강 기간, 승인 상태, 진도 및 나머지 업무 데이터는 정확히 비교한다.

## 발견하여 수정한 호환성 차이

- Django 관리자 사이트 이름의 요소 변경에 맞춰 태그 대신 `#site-name`으로 스타일을 적용한다.
- 관리자 비밀번호 요약의 새 `bdi` 요소에서 긴 문자열이 화면을 넘지 않게 한다.
- 권한 선택 위젯이 링크에서 버튼으로 변경되어, 새 버튼에도 44px 터치 영역을 적용한다.
- 로그아웃 글자 크기와 헤더 높이를 조정하고, 자동 검사에 헤더 잘림 검증을 추가한다.
- 인자 없는 `format_html()` 사용 4곳을 수정해 사용 중단 경고를 없앤다.
- 운영 준비 점검에 실행 중인 Django 버전을 표시한다.
- 배포 전 로컬 검증 환경의 Django 버전이 배포 요구 버전과 일치하는지 확인한다.

## 배포와 복귀

- 운영 전환 전에 로컬 및 GitHub의 두 검증 작업 성공을 확인한다.
- `onedu-remote.ps1 -Action backup-db`로 전환 직전 DB 덤프를 생성한다.
- 기존 커밋의 소스 아카이브를 보관하고 기존 요구 버전으로 다시 빌드할 수 있게 한다.
- 검증한 Python 3.12 가상 환경을 활성화한 상태에서 기존 배포 명령을 사용한다.
- 전환 후 health, readiness, 공개 페이지, 관리자 로그인 및 정적 파일 응답을 확인한다.
- 이번 업그레이드에는 업무 DB 마이그레이션이 없다. 복귀가 필요하면 기존 코드와 4.2 실행 환경으로 되돌리고 정적 파일을 다시 수집한다. 이전 DB 덤프를 운영 DB에 덮어쓰지 않아 전환 후 생성된 데이터도 유지한다.
- DB 덤프 복구는 별도 사고 대응 절차이며, 실제 운영 덤프의 복원 시험은 이번 가상 데이터 검증과 구분한다.

## 검증의 한계

브라우저 검사는 Chromium/WebKit의 화면 에뮬레이션이다. 실제 휴대폰, 카카오톡 내장 브라우저 및 운영 DB 전체 사본을 사용한 시험은 아니다.
테스트 파일 해시 검사는 업로드 보존 검증이며, 실제 운영 영상 전체의 재생 검사나 백업 복원 검증을 대신하지 않는다.

공식 자료: [업그레이드 절차](https://docs.djangoproject.com/en/5.2/howto/upgrade-version/), [5.2 변경 사항](https://docs.djangoproject.com/en/5.2/releases/5.2/).
