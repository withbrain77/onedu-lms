# 강사 권한과 수강료 정산 운영

## 계정과 담당 강의

1. 강사는 일반 회원으로 가입합니다.
2. 관리자가 **회원 관리 → 사용자 → 해당 회원 → LMS 정보 → 강사 권한**을 체크합니다. 관리자 권한(is_staff)은 부여하지 않습니다.
3. **강사·정산 관리 → 담당 강사·정산 기준**에서 회원과 강의를 연결합니다. 전체 담당이면 차시는 비우고, 차시 담당이면 해당 강의의 차시를 선택합니다.
4. 같은 계정으로 상단 메뉴 또는 내 정보의 **강사실**을 이용하고, 수강 신청한 강의는 기존 **내 강의실**에서 학습합니다. 강사 지정은 영상 시청 권한을 자동으로 부여하지 않습니다.

## 금액 설정

- 정액: 유료 신규 수강 1건당 **이 강사에게 지급할 금액**을 입력합니다.
- 비율: `실제 입금액 × 강의 수강료 중 배분 비중 ÷ 100 × 강사 지급률 ÷ 100`으로 계산합니다. 예: 30,000원 × 50% × 40% = 6,000원.
- 원 미만은 버립니다. 실제 입금액 0원은 강사료도 0원입니다.
- 재수강 적용 여부를 선택합니다. 현재는 체크하면 같은 금액·비율을 적용합니다. 체크하지 않은 재수강은 적용 기준이 없으면 계산을 차단하므로 별도 약정이 필요한 건은 운영자 확인이 필요합니다.
- 입금 확인일에 유효한 기준을 사용합니다. 계산 이력이 생긴 기준은 금액 등을 변경할 수 없습니다. 기존 기준의 종료일을 지정하고 다음 날부터 새 기준을 등록합니다.
- 같은 기간에 강의 전체 담당과 차시별 담당 정산을 혼용하거나, 동일 강사의 같은 담당 범위를 중복 등록할 수 없습니다. 전체 강사료가 실제 입금액보다 많으면 계산을 차단합니다.
- 실제 계약 금액은 운영자가 입력합니다. 도입 시 임의로 강사 권한·배분율·지급액을 지정하지 않습니다.

## 수강료 확인부터 지급 기록까지

1. 유료 신규 수강의 **입금 확인**, 유료 재수강의 **승인** 시 수강료 거래 초안이 생성됩니다. 기존 입금·승인 기능과 메일 동작은 유지됩니다.
2. **수강료 거래**에서 실제 입금액과 입금 확인일을 입력하고 저장합니다. 재수강 승인은 입금 근거가 아니므로 날짜·금액을 직접 확인해야 합니다.
3. 목록에서 거래를 선택하고 **실제 입금액 확인·강사료 계산**을 실행합니다. 계산은 한 번만 반영됩니다. 자동 송금이나 자동 정산 확정은 하지 않습니다.
4. **강사료 정산 내역**에서 검토할 강사·발생 기간을 필터링한 후 **정산 확정**을 실행합니다.
5. 실제 송금을 완료한 후 해당 내역에 **지급 완료 처리**를 실행합니다. 처리자와 일시를 보관합니다. 세금·공제 계산, 은행 송금 기능은 포함하지 않습니다.

## 환불

원거래가 계산된 후 **수강료 환불**에 금액·확인일·사유를 등록하고 목록에서 **환불 확인·강사료 차감 반영**을 실행합니다. 수강 취소만으로 환불을 추정하지 않습니다.

정액·비율 모두 원거래 강사료에 환불 비율을 적용해 음수 내역을 별도로 만듭니다. 부분 환불을 여러 번 해도 누적 기준으로 계산하므로 전액 환불 시 원래 강사료가 정확히 상쇄됩니다. 입금액을 초과하는 환불은 차단합니다. 이미 지급된 금액은 지우지 않고 차감 내역을 다음 정산에서 함께 확인합니다.

## 강사실과 과거 자료

- 본인 강의와 본인 강사료만 조회할 수 있습니다. 수강생 개인 정보와 다른 강사의 정산 기준은 제공하지 않습니다.
- 기간별 유료 신규·재수강 건수, 해당 거래 입금액, 환불액, 정산 대기·확정·지급 완료 금액을 확인하고 CSV를 내려받을 수 있습니다.
- 강사료 내역에는 강의명·담당 범위·당시 지급 기준이 보존됩니다.
- 학습 인원·수료 인원은 **현재까지의 누적 현황**으로 별도 표시합니다. 기간별 시청 시간을 추정하지 않습니다.
- 도입 전 거래의 실제 입금액은 알 수 없으므로 모두 미확인 상태로 가져옵니다. 당시 금액과 적용 기준을 확인하기 전에는 강사료에 합산하지 않습니다. 입금일이 없는 거래는 기간 미분류로 표시합니다.
- 권한을 해제하면 강사실과 CSV 모두 즉시 접근이 차단되며 일반 수강생 기능은 유지됩니다. 금융 기록에 연결된 신청·강사·강의는 삭제 대신 비활성화·비공개로 관리합니다.
