# 모바일 화면 종합 점검 — 2026-09-18

## 범위와 결과

격리된 로컬 테스트 DB에 긴 회원 이름·이메일·강의명·차시명·공지와 URL, IPv6 접속 기록, 다운로드 기록, 재수강 대기, 메일 실패, 영상 변환 실패, 시험 문제·보기·응시 결과, 수료증 데이터를 준비했습니다. 운영 DB에는 테스트 데이터를 추가하지 않았습니다.

Chromium의 Android 휴대폰 모사에서 다음 조건을 사용했습니다. 수치는 CSS 픽셀이며 실제 기기 해상도와 다릅니다.

- 세로: 320×740, 390×844, 412×915
- 가로: 915×412
- 확대: 390×844에서 기본 글자 크기 200%

직접 추가가 금지된 관리자 기록 화면 5개는 각 조건에서 403 응답을 확인했고, 위 레이아웃 점검 합계에서는 제외했습니다. 총 요청 조합은 460개입니다.

최종 검사에서는 페이지 가로 넘침, 일반 본문 넘침, 입력칸·버튼의 가림, 수강생 페이지 마지막 부분의 하단 메뉴 겹침, JavaScript 실행 오류가 발견되지 않았습니다. 접근성용 숨김 문구와 아이콘의 대체 텍스트, 명시적으로 스크롤하는 표, 의도된 말줄임은 실제 잘림과 구분했습니다. 일부 화면은 스크린샷으로도 확인했습니다.

## 발견하고 수정한 항목

1. **관리자 편집 입력칸**: Django의 화면 폭 기준 계산이 카드 내부 폭보다 커서 입력칸 끝이 잘렸습니다. 실제 카드 폭에 맞추고, 좁은 화면의 라벨과 입력 영역을 위아래로 배치했습니다.
2. **연결 항목 선택과 버튼**: 강의·차시·수강 선택 상자가 추가·수정·보기 버튼을 밖으로 밀었습니다. 선택 상자와 연결 버튼이 줄을 나눠 사용하도록 수정했습니다.
3. **여러 항목을 편집하는 표**: 차시·자료·문제·보기의 내부 fieldset이 표를 잘랐습니다. 표 컨테이너에서 좌우 스크롤할 수 있게 바꾸고 안내와 키보드 접근을 추가했습니다.
4. **긴 텍스트**: 공지의 긴 URL, 회원 보고서의 IPv6 주소, 관리자 페이지 부제의 긴 이메일을 줄바꿈하도록 수정했습니다.
5. **로그인 하단 회사 안내**: 320px에서 한 줄 고정 문구가 왼쪽으로 밀렸습니다. 필요한 만큼 줄바꿈하도록 수정했습니다.
6. **글자 확대**: 강의 이미지가 없을 때의 기본 문구와 개인정보 문의 이메일에 줄바꿈을 적용했습니다.

## 조작 확인

- 강의 연결 선택과 추가·수정·보기 버튼 접근
- 자료 편집 표 좌우 이동, 새 자료 행 추가와 제목 입력
- 권한 선택 목록의 항목 추가·제거
- 관리자 필수 항목 누락 오류와 수강생 이메일 오류 표시
- 오류 표시 후에도 탈퇴 요청 버튼 접근 가능
- 영상 화면의 차시·자료·진도 탭 전환

조작은 격리된 테스트 환경에서 수행했으며, 정상 저장이나 실제 알림 발송을 실행하지 않았습니다. Django의 관리자 테마·로그인 관련 기존 테스트 18개, JavaScript 문법 검사와 변경 파일 검사도 통과했습니다.
