# 재수강 안내·알림과 아이디 중복 확인

## 재수강 정책 설정

관리자 → 강의 → 해당 강의 → **유료 강의 재수강 정책**에서 재수강 이용료와 기간을 함께 설정합니다.

- 금액·기간 모두 미설정: 운영자 문의로 안내하며, 금액을 추정하거나 계좌 입금을 유도하지 않습니다.
- 이용료 0원과 기간 설정: 입금 없이 관리자 승인 후 연장합니다.
- 이용료 1원 이상과 기간 설정: 재수강 금액·기간, 설정된 입금계좌와 계좌 복사 버튼을 제공합니다.
- 무료 강의: 기존 기본 수강 기간과 즉시 재수강 방식을 사용합니다.

안내는 로그인한 회원의 기간 만료 강의 상세, 재수강 신청 화면, 내 강의실에 표시됩니다. 신규 수강 비용과 기존 수강의 입금 상태는 재수강 비용·상태와 구분합니다.

신청 당시 금액·기간을 신청 기록에 보관합니다. 강의 정책 변경은 새 신청부터 적용됩니다. 이번 기능 이전 신청과 설정 없이 접수한 신청은 운영자 문의 대상이며, 이후 설정한 강의 요금으로 덮어쓰지 않습니다. 승인 시 관리자가 입력한 연장 날짜를 우선하며, 날짜가 비어 있으면 신청 당시 기간을 사용합니다. 미설정 신청은 기존 기본값인 30일 연장을 사용하므로 승인 전 날짜를 확인합니다.

## 알림

유료 재수강 신청은 관리자에게, 승인·반려는 수강생에게 이메일을 보냅니다. 기존 수강 신청·승인 알림 설정과 관리자 수신자 설정을 따릅니다. 거래가 정상 확정된 후 발송하며, 동일 상태에서 메모만 다시 저장하면 재발송하지 않습니다. 무료 즉시 재수강은 이 유료 신청 알림 대상이 아닙니다.

기존 메일 발송 큐·재시도·로그를 사용합니다. 관리자 → 메일 발송 로그에서 재수강 유형과 해당 신청을 확인하고 실패한 메일을 재발송할 수 있습니다. 이미 신청 상태가 바뀐 알림은 재발송하지 않습니다.

재수강 승인으로 기간이 갱신되면 7일 전 만료 알림 기록을 초기화합니다. 기존의 진도·수료 상태는 유지하며, 수료 완료자의 만료 알림 제외 정책도 유지합니다.

## 아이디 확인

회원가입에서 아이디 입력을 잠시 멈추거나 다른 칸으로 이동하면 사용 가능 여부를 확인합니다. 영문·숫자 조합, 최대 20자, 대소문자를 구분하지 않는 중복 검사를 기존 가입 규칙과 동일하게 적용합니다. 입력값이 바뀌면 이전 조회 결과를 버립니다.

통신 실패 시 확인 실패 안내를 표시하고 회원가입은 계속할 수 있습니다. 사전 확인은 아이디를 예약하지 않으며, 최종 제출 시 서버의 중복 검사를 다시 거칩니다. 이메일 등 다른 회원 정보는 이 조회로 제공하지 않습니다.

## 검증

`accounts.test_username_availability`, `enrollments.test_reenrollment_flow`에서 정책별 표시, 신청 조건 보존, 발송·반려·롤백·재시도, 만료 알림 재발송, 중복 아이디 최종 검증을 확인합니다. 브라우저 검증은 두 엔진에서 안내 표시와 아이디 조회 성공·실패·응답 순서 변경을 확인합니다. 모든 테스트는 별도 테스트 데이터베이스와 가짜 메일 백엔드를 사용합니다.
